# luisrosa.github.io

Personal research website for Luis Fernando Rosario Freytes.

This is intentionally a small static site: plain HTML and CSS, no build step, no framework, and no CI required.

## Local preview

From the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publishing

The repository is intended for GitHub Pages as the user site at `https://luisrosa.github.io`.

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then publish `main` from `/(root)`.
